# Low-correlation blend experiment

Record before calculating blend outcomes. Use the latest selected strategy (full-period development excess Sharpe 1.132) as the base. Screen the previously completed expanded, weekly and refinement candidates on the identical 2017–2025 sessions. Use excess-return correlation, not price correlation. Eligible diversifiers must have positive standalone excess Sharpe of at least 0.30 and correlation no greater than 0.30 with the base. Select up to three highest standalone-Sharpe eligible candidates, allowing only one allocation variant of each underlying forecast model/source round (weekly/refinement variants grouped by model/sleeve). If none qualifies, report that result rather than silently relaxing criteria.

Test exactly two fixed diversifier allocations per selected strategy: 25% and 50%, with the remainder in the base. Do not optimize allocation weights or select on 2018–2025. All candidates trade USO, so combine signed exposures, net them, and simulate one daily-rebalanced account; do not average already-net strategy returns and call that execution. Both inputs retain their saved chronological predictions/position rules. Gross target cap 2x; same cash proxy, 5 bps trading costs, 3% annual short borrow, cash-rate plus 2% long financing, no short collateral rebate. Include the unchanged base as a control.

Report full 2017–2025 results, individual-year Sharpe, the requested 2018–2025 sensitivity, correlation, costs and worst drawdown. Freeze component identities/weights for cost stress. A paired block-bootstrap difference is descriptive only: both component screening and blend selection use development outcomes and cannot establish independent improvement. This is a further logged retrospective search, not an untouched test. Keep 2026 closed.
