# Frozen time-series model batch

Six primary configurations: existing seven-feature ridge control, lagged gradient boosting and lagged adaptive ridge, each at 5/21-session horizons. Full 2017–2025 scoring; 2026 remains unopened. No subsequent parameter search in this batch.

Reuse the frozen scarcity batch's release-aligned features and lineage. Existing ridge uses four seasonal flow/utilization features and three inventory innovations. The lagged models use those seven, three scarcity states and two demand states (12 current features), plus lags 1, 2, 4 and 8 retained releases of the three innovations, three scarcity states and two demand states (32 lag features; 44 total). Daily feature copies are collapsed to the FIRST observed daily row for each release without skipping nulls. For conservatism, each extracted event becomes available at that row's actual signal cutoff, never before its archived release availability. Lag observation gaps must lie within 7*k ±3 days; missing/quarantined weeks may disable a lag rather than masquerading as a regular weekly sequence. Current events expire 21 days after observation. No backward filling or missing-value imputation.

This tests two model-plus-feature packages against the existing control, not a pure architecture ablation. Daily training labels overlap and weekly inputs repeat; daily row count is not an independent sample count.

Quarterly expanding fitting; at least 252 complete training rows; horizon outcome must end strictly before first test signal. Ridge alpha 100. Boosting: HistGradientBoostingRegressor, 100 iterations, learning rate .04, max_leaf_nodes 7, min_samples_leaf 60, l2_regularization 20, early_stopping False, random_state 49. Adaptive ridge: alpha 100, exponentially weighted completed training rows with half-life 730.5 calendar days, weights normalized to mean one, training-only weighted StandardScaler. Coefficients update quarterly. No random validation split.

Keep forecast normalization, completed-outcome error RMS, 0.25*RMS strength hurdle, 15% trailing risk target, 5% risk floor, 2x target cap, weekly inventory execution, 0.10-equity deadband and horizon-specific cost gate from scarcity. Forecast from 2015 for warmup. Fixed portfolio: 37.5% prior macro/news +37.5% inventory +25% prior technical diversifier; net positions before costs. Costs 5bps/traded dollar, 3% annual short borrow, cash plus 2% leveraged-long financing, no short-collateral rebate. Standalone inventory metrics are diagnostics, not extra primary selections.

Require both ridge controls to reproduce the corresponding scarcity-batch daily returns within 1e-11. Report all six portfolios, individual-year Sharpe, coverage, normalized return-forecast RMSE and correlation on common valid dates by horizon, standalone sleeve metrics, cost stress and descriptive paired block-bootstrap intervals. Forecast metrics only use outcomes completed before 2026. Primary selection uses full-period net cash-excess Sharpe. Preserve controls and all outcomes, even if no improvement. Prior repeated development selection and all market-data/execution limitations persist.
